# ConflictCore — Integrated Workspace

**Project:** Conflict Resolution-Based Multi-User File Management System
**Course:** B.Tech CSE Project-Based Learning (PBL)
**Team:** OSDBMS-V-2026-T206 — Graphic Era (Deemed to be University)

## Overview

ConflictCore combines Operating Systems and Database Management Systems principles into a multi-user file management system:
- **Backend (Anshika Lakhera):** Node.js REST API with Hono, multipart file upload/download, storage management, and OS dispatching.
- **OS Kernel (Avni Negi):** Process lifecycle state machine, FCFS/SJF/Priority schedulers, file locking, Wait-For Graph cycle detection, and victim recovery.
- **DBMS & Data Access Layer (Shubham Kumar):** 7 core tables, transaction safety, repository pattern, and relational queries in MySQL 8.4.
- **Frontend (Jahnvi Sharma):** Interactive web dashboard for file exploration, process monitoring, scheduling visualization, lock tracking, and deadlock recovery.
